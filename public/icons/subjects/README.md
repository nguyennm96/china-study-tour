# Subject POI icons

The live map uses eight original **2D SVG** icons drawn for this project:
`drone.svg`, `delivery.svg`, `mobility.svg`, `payment.svg`, `robots.svg`,
`interfaces.svg`, `hardware.svg` and `logistics.svg`.

Each uses a 64 × 64 viewBox, rounded 3-unit navy strokes, orange and pale-orange
fills, and a transparent background. They depict a delivery drone, scooter,
passenger car, contactless payment, coffee robot, translation display,
microchip and parcel conveyor. The map displays them at 26px inside white
36px POI markers with a location pointer and a 44px click target. Labels remain
on hover/focus/selection. The mascot renders above both regular and selected POIs.

These are code-native vector drawings, not raster edits. The preceding 3D
Imagegen explorations and their original prompts are preserved in
`outputs/subject-icons-3d/` at the project root; they are no longer loaded by the map.
